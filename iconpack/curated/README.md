# Curated icon library

Persistent, highest-priority icons for the Theme Park pack.

- `png/` — stable drawable-name PNGs (`wechat.png`, `chrome.png`, …)
- `index.json` — package/component → drawable + provenance

`tools/import_iconlab_export.py` **never overwrites** files in `png/`.
A Nada APK is only a one-time source. After extract, stop using that APK.
